# WellConX - Real-Time Medical Device Monitoring Platform
## Professional Portfolio Documentation

---

## Project Overview

**WellConX** is a comprehensive B2B healthcare portal designed for real-time monitoring of medical devices, featuring advanced HL7 data integration, patient management, and sophisticated analytics. This cutting-edge platform serves healthcare professionals with intuitive interfaces and powerful monitoring capabilities.

### Key Technologies Used
- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom animations
- **Charts**: Chart.js and Recharts for data visualization
- **Build Tool**: Vite for optimal performance
- **Icons**: Lucide React icon library
- **Animations**: Framer Motion for smooth interactions
